# درباره iran-resolvers

در این روزهای قطعی اینترنت ایران، یکی از مواردی که به دستیابی ایرانیان در اینترنت آزاد کمک میکنه، داشتن یک لیست کامل ازResolverهاست.

بنابراین، در اینجا تلاش در این هست که لیستی کامل از این Resolverها رو تهیه و در اختیار مردم عزیز ایران قرار گیرد.

به امید روزی که همه به اینترنت آزاد واقعی دست پیدا کنیم. 🕊
